Cardputer ADV Calculator

M5Stack Cardputer / Cardputer ADV 用 関数電卓ファームウェア — かんたんインストール

方法1: ブラウザから書き込む(推奨)

PCに何もインストールせず、ブラウザだけで書き込めます。

対応ブラウザ: Chrome または Edge(Web Serial API が必要)。Safari / Firefox では動作しません。
  1. Cardputer ADV を USB Type-C ケーブルで PC に接続する
  2. 下のボタンを押す → 表示されるリストから接続したデバイスのポートを選ぶ → INSTALL を押す
  3. 書き込みが終わったら自動的に再起動し、電卓画面が表示されます
お使いのブラウザは対応していません。Chrome または Edge で開いてください。 この機能を使うには https 接続が必要です。

2回目以降のアップデートでも、保存済みの履歴・Wi-Fi設定・時刻設定は消えません(設定用の記憶領域は書き換え対象外のため)。

方法2: esptool.py で手動書き込み

Web Serial が使えない環境向けの代替手段です。Python が必要です。

  1. bootloader.bin / partitions.bin / boot_app0.bin / firmware.bin の4ファイルを同じフォルダにダウンロードする
  2. esptool をインストールする: pip install esptool
  3. Cardputer ADV を USB Type-C で接続し、接続されたシリアルポート名を確認する (Mac: ls /dev/cu.usbmodem* / Windows: デバイスマネージャーで COM* を確認)
  4. 以下のコマンドを実行する(<PORT> は自分の環境のポート名に置き換える):
python -m esptool --chip esp32s3 --port <PORT> --baud 460800 \
  --before default_reset --after hard_reset write_flash -z \
  --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x0000 bootloader.bin \
  0x8000 partitions.bin \
  0xe000 boot_app0.bin \
  0x10000 firmware.bin

使い方

書き込み後は、キーボードで数式(例: 2*sin(pi/4)+sqrt(16))を入力して Enter で計算できます。詳しい使い方は 操作マニュアル を参照してください。
